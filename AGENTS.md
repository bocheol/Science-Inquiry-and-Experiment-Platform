# Project instructions

- 작업 시작 시 `PROJECT_STATUS.md`는 항상 전체를 읽고, `CURRENT_DECISIONS.md`도 확인한다.
- `implementation_plan.md`는 현재 기능에 해당하는 절만 읽는다. 큰 단계 시작이나 문서·구현 충돌이 있을 때만 전체를 다시 읽는다.
- 수업 일정 우선순위를 지키고, 원본 계획서·보고서·Google Sheet 구조를 추측하지 않는다.
- 학생 데이터와 비밀값을 보호하고, 제거된 팀원의 과거 기록과 확정 권한 규칙을 보존한다.
- 의미 있는 구현·검증·배포 후 `PROJECT_STATUS.md`를 갱신한다. 전체 작업 완료 전에는 Git 초기화·커밋·푸시를 하지 않는다.
